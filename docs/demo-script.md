# 知农时 · 3 分钟演示脚本（逐句稿）

> 目标：3 分钟讲清价值并完整走完流程；断网也能演示（mock 兜底 + 备用录屏）。
> 四个硬性验收线：接口 < 2s ／ 375px 无横滚 ／ 首屏 3 秒出结论 ／ 天气降级标数据时间、识别必人工确认且失败回落。

## 0:00–0:20 开场（一句话说清）

「农户不缺信息，缺的是把信息变成『今天该不该干』的那一步判断。知农时只回答一个问题——今天该不该干。」

## 0:20–0:50 输入（三个字段或一张照片）

1. 打开表单页：「输入三个字段——作物品种、播种日期、所在地。说不清品种？拍一张照片。」
2. 用模糊输入敲「大蒜」，展示联想候选，点选「山东金乡大蒜」。
3. 「播种日期 3 月 15 日，所在地山东金乡。」（默认值已预填，减少输入。）
4. 或点击「拍一张照片」→ 识别给出 3 个候选与置信度 → **「识别只给候选，必须你点一下确认。」** 点选确认。

## 0:50–1:40 时间线展开（三层信息）

1. 页面顶部首屏即出结论：**「今天该不该干」**（3 秒内可见）。
2. 沿时间轴展开：播种 → 出苗 → 返青追肥 → 抽薹打药 → 灌溉 → 采收窗口。
3. 指出三层信息：要干什么 ／ 该不该干·什么时候干 ／ 什么时候有讲究。
4. 「确定信息用实线，天气预报用虚线——我们从不把预测说成确定。」

## 1:40–2:20 关键结论（价值所在）

1. 点开「返青追肥」节点：「窗口内 3 天累计降雨 18mm，命中施肥规则包 → 建议推迟，直接给出改期日。」
2. 展示不同规则包：打药怕雨冲风飘高温、灌溉有雨即暂缓、采收遇雨提前抢收。
3. 展示节日提醒：「中秋销售窗口提前 15 天，别等卖菜前一周才想起。」

## 2:20–2:50 容错与信任底线

1. 「天气不准？我们只给窗口建议并附改期日；**取不到数据就标注数据时间，绝不编造。**」（可现场断网演示降级。）
2. 「识别认错作物？必须人工确认才生成时间线，失败直接回落搜索框，不让用户卡在第一步。」

## 2:50–3:00 收尾

「知农时，基于华为云 CodeArts 构建。今天该不该干，一眼就有答案。」
