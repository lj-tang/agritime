## 二、许可合规结论

| 数据类别 | 许可类型 | 允许再利用 | 合规结论 |
|---------|---------|-----------|---------|
| 作物农事规程 | 政府公开数据 + CC BY 4.0 | 是 | 合规。政府数据可自由使用，CC BY 4.0 要求署名 |
| 气象阈值 | 政府公开数据 + CC BY 4.0 | 是 | 合规。同上 |
| 物候期 | CC BY 4.0 + 政府公开数据 | 是 | 合规。同上 |
| 节气农事 | 政府公开数据 | 是 | 合规。政府公开数据可自由使用 |
| 销售节日 | 政府公开数据 | 是 | 合规。同上 |
| 新增因子阈值 | 政府公开数据 + FAO 标准 | 是 | 合规。FAO56 蒸散量标准为公开学术资料 |
| 气象局实时数据 | 政府公开数据 | 是 | 合规。中国气象局及地方气象局数据为政府公开数据 |
| 盘古预测数据 | 允许调用的商业服务许可 | 是 | 合规。华为云盘古大模型预测服务经授权调用，预测结果标注为 predicted |

**权威来源优先级**：国家农业机构 > 国际组织（FAO/CGIAR）> 公开平台（Open-Meteo）> 商业源（盘古）

**合规红线**：
- 仅采用「开放许可或政府公开数据」白名单内的来源
- 许可不明确或禁止再利用的来源一律拒绝引入
- 所有数据均不含个人隐私信息
- 预测类数据必须标注 `certainty=predicted`，禁止标注为观测数据
- 气象局与盘古接口凭据仅通过环境变量注入，不硬编码入库

## 三、凭据与拒绝记录说明

### 凭据说明

来源登记与数据文件中**不含任何真实密钥、令牌或账号凭据**。v2 既有来源均为公开可访问的开放数据。v3 新增的气象局实时接口与盘古预测服务凭据通过环境变量注入：

| 环境变量 | 用途 | 配置说明 |
|---------|------|---------|
| `CMA_API_BASE` | 气象局接口基址 | 必填，启用气象局实时源 |
| `CMA_API_KEY` | 气象局接口凭据 | 选填，部分接口需要 |
| `CMA_TIMEOUT_MS` | 气象局超时阈值 | 默认 1500ms |
| `LOCAL_CMA_API_BASE` | 地方气象局接口基址 | 选填，补充源 |
| `PANGU_ENDPOINT` | 盘古预测服务端点 | 必填，启用盘古预测源 |
| `PANGU_API_KEY` | 盘古预测服务凭据 | 选填，部分接口需要 |
| `PANGU_TIMEOUT_MS` | 盘古超时阈值 | 默认 3000ms |

### 拒绝记录

| 来源名称 | 发布机构 | 拒绝原因 |
