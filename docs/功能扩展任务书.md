**适用范围**：全员功能开发，统一收敛至 `agritime/` 目录，不分前后端，按功能模块认领

## 一、项目整体目标

基于现有「会看天的农事日历」基础版本，围绕**农事全链条指导、多模态交互、安全多端**三大方向迭代升级，统一项目目录规范，全员按功能模块全链路开发，保留原有三层架构与降级机制，核心接口性能维持 p95 < 2s。

## 二、前置动作：统一目录规范

所有代码、数据、资源全部收敛至 `agritime/` 根目录，现有代码按此结构迁移，后续新功能严格遵循。

```
agritime/
├── frontend/          # 前端页面与交互
│   ├── pages/         # 业务页面
│   ├── components/    # 公共组件
│   └── assets/        # 图片、动画、语音等静态资源
├── backend/           # 后端服务
│   ├── api/           # HTTP 接口层
│   ├── service/       # 业务逻辑层
│   ├── model/         # 数据模型
│   └── middleware/    # 限流、安全中间件
├── data/              # 公共数据与规则库
│   ├── crop-base/     # 作物基础库（学名/俗称/属性）
│   ├── guidance/      # 农事指导规则库
│   ├── region/        # 地理与环境数据
│   └── industries/    # 农林渔牧扩展品类（暂缓，预留目录）
├── shared/            # 多端共享逻辑
│   ├── utils/         # 通用工具函数
│   └── constants/     # 全局常量与数据协议
└── docs/              # 项目文档
    └── taskbook.md    # 本任务书
```

### 模块1：主页天气与视觉动态适配

**任务编号：T01**

- **任务描述**：主页新增当前地点与实时天气信息展示；根据实时天气（晴/雨/多云/雪等）与季节，自动切换主页背景图、主题色与微动效，模拟天气预报视觉效果。
- **验收标准**：
  1. 主页顶部展示「当前地点 + 实时温度 + 天气状况 + 湿度风速」
  2. 晴/雨/多云/雪4类天气对应不同背景与动效，切换无卡顿
  3. 天气数据与后端天气接口保持一致，异常时降级为默认主题
- **对应目录**：`frontend/pages/index` / `frontend/assets/weather-bg` / `backend/service/weather`

---

### 模块2：作物名称标准化与模糊搜索

**任务编号：T02**

- **任务描述**：建立作物「学名-俗称-别名」映射库，用户输入俗称、学名、简称均可命中；后端统一转换为标准学名存储与计算；支持模糊匹配与输入联想，输入误差≤2字符可命中目标作物。
- **验收标准**：
  1. 输入「西红柿/番茄/tomato」均可命中「番茄」标准作物
  2. 搜索框支持输入联想，下拉展示Top5匹配作物
  3. 后端所有接口仅接收与返回标准学名，前端展示可兼容俗称
- **对应目录**：`data/crop-base/alias.json` / `backend/service/crop` / `frontend/components/search`

---

### 模块3：全链条农事指导体系

**任务编号：T03**

- **任务描述**：农事时间线节点补充全流程指导内容，覆盖4类核心场景，内容与作物、天气、土壤联动：
  1. 浇水：推荐浇水方式（滴灌/漫灌/喷灌）、持续时长、亩均水量
  2. 施肥：推荐肥料类型、N/P/K配比、施肥用量与方法
  3. 病虫害：常见病虫害症状识别 + 防治方案与用药建议
  4. 农具：对应农事节点推荐所需农具清单
- **验收标准**：
  1. 每个农事节点点击可展开详细指导，覆盖以上4类内容
  2. 指导参数随天气、土壤条件动态调整
  3. 病虫害支持文字查询，返回匹配度Top3结果
- **对应目录**：`data/guidance/` / `backend/service/guidance` / `frontend/components/node-detail`

---

### 模块4：时间体系、天气数据源分级与提醒

**任务编号：T04**

- **任务描述**：
  1. 以用户确认的播种日期为起点，生成农事时间线
  2. **时间提醒**：关键农事节点（浇水、施肥、病虫害防治、采收等）支持开启提醒，前端展示倒计时，到点触发提醒通知
  3. 时间选择支持「手动输入」+「日期轮盘」两种交互，**选择范围严格限制为：过去 2 年 ~ 未来 30 天**
  4. 数据源分级：过去日期调用历史气象数据库，未来日期调用 Open-Meteo 预测 API
  5. **预测标注**：未来天气均为预测数据，**自第 5 天起**（含第 5 天）的节点统一标注「天气为预测数据，仅供参考」，避免误导
- **验收标准**：
  1. 日期选择器支持轮盘滑动与键盘输入，范围严格限制在过去 2 年 ~ 未来 30 天，超出范围不可选
  2. 过去 2 年内返回真实历史气象数据，未来日期返回预测数据
  3. 未来第 5 天起的节点均有明确「仅供参考」标识，无误导性表述
  4. 关键农事节点可开启提醒，前端展示倒计时，到点有提醒反馈
- **对应目录**：`backend/service/weather` / `backend/service/reminder` / `frontend/components/date-picker` / `frontend/components/reminder` / `data/weather/`
