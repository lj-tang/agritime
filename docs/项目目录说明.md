## 一、后端服务（甲负责）

路径：`/opt/crop-calendar/`

```
/opt/crop-calendar/
├── src/                          # Java 源码（13 个 .java 文件）
│   └── com/cropcalendar/
│       ├── Server.java           # 入口，注册路由，监听 8080
│       ├── config/
│       │   └── AppConfig.java    # 配置加载（环境变量 > properties > 默认值）
│       ├── api/                  # HTTP 层（只收参数发响应）
│       │   ├── HealthHandler.java
│       │   ├── TimelineHandler.java   # POST /api/timeline
│       │   ├── ChartHandler.java      # POST /api/chart（异步图表）
│       │   ├── RecognitionHandler.java
│       │   └── HttpSupport.java
│       ├── orchestration/        # 编排层（甲的地盘）
│       │   ├── TimelineOrchestrator.java
│       │   └── CacheStore.java
│       ├── compute/              # 计算层（乙的地盘）
│       │   ├── ComputeStub.java       # 六个核心函数
│       │   └── LlmService.java        # 华为云盘古大模型
│       └── util/
│           ├── Json.java              # JSON 序列化
│           └── JsonParser.java        # JSON 解析
├── build/classes/                # 编译后的 .class 文件（运行用）
├── application.properties         # 配置文件
├── crop-protocols.json           # 作物规程数据（5 种作物）
├── market-festivals.json         # 节日销售规则
├── deploy/                       # 部署脚本
│   ├── ecs-start.sh
│   ├── ecs-stop.sh
│   └── crop-calendar.service
├── server.log                    # 运行日志
└── server.pid                    # 进程 PID
```

**运行状态**：端口 8080，PID 见 server.pid
**启停**：`bash /opt/crop-calendar/deploy/ecs-start.sh` / `ecs-stop.sh`
