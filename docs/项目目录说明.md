## 二、后端接口一览（15 个）

| 路径 | 方法 | 说明 |
|---|---|---|
| `/health`、`/api/health/detail` | GET | 健康检查 |
| `/api/crops` | GET | 作物清单 |
| `/api/timeline` | GET/POST | 生成农事时间线 |
| `/api/chart` | POST | 生长曲线/图表数据 |
| `/api/recognition` | POST | 作物识别（拍照） |
| `/api/plots/environment` | GET | 地块实时环境（温湿度/土壤/水质，5 分钟缓存） |
| `/api/disease/detect` | GET | 病害检测 Top3（文字匹配，图片不参与识别） |
| `/api/geo/reverse` | GET | 逆地理编码（小区级中文地名） |
| `/api/recommend` | GET | 种植推荐（月份+纬度+市场） |
| `/api/support/*` | GET/POST | 客服工单：ticket / tickets / reply / close |
| `/api/auth/*` | POST/GET | 注册 / 登录 / 退出 / me |
| `/api/me/*` | GET/POST | 个人数据（地块、作物、历史） |
| `/api/admin/*` | GET/POST | 超管：账号、文件、开关、统计 |
| `/api/site-config` | GET | 站点开关配置 |

统一响应：`{"code":0,"message":"ok","data":...}`，错误走 `HttpSupport.error(code,msg)`。

## 三、服务器布局

| 项 | 路径 |
|---|---|
| 站点根目录（= git 工作区） | `/agritime` |
| nginx 站点配置 | `/etc/nginx/sites-enabled/agritime`（副本在 `deploy/nginx/agritime.conf`） |
| systemd 服务 | `crop-calendar.service`（`WorkingDirectory=/agritime/backend`） |
| 敏感配置 | `/etc/agritime.env` |
| 应用日志 | `/var/log/crop-calendar/app.log`、`app.err.log` |
| 账号库（含密码摘要，不入库） | `/agritime/backend/var/users.json` |
| 客服工单 | `/agritime/data/support/tickets.json` |

静态资源对外路径：`/assets/`、`/components/`、`/shared/`（`shared` 在仓库根，需 nginx 单独 alias，否则浏览器取不到）。

## 五、与任务书目录的差异（有意为之）

| 任务书要求 | 实际做法 | 原因 |
|---|---|---|
| `frontend/pages/{recommend,plots,calendar,...}/` 一模块一目录 | 单壳 `index.html` + `.content-pane[data-module]` 切换 | 6 个板块共享侧栏/天气/账号态，拆成 6 个页面会重复加载公共资源；板块样式与脚本仍按模块分文件 |
| `data/industries/aquaculture/` | 仅有 `.gitkeep` | T09 渔业未开工 |
| `miniprogram/` | 不存在 | T11 小程序未开工 |
| `frontend/pages/disease/` 等 | `assets/js/disease.js` + `assets/css/disease.css` | 同上，SPA 下按 js/css 分模块更自然 |

除此之外：`backend` 已按 api/service/model/middleware 分层，`shared/{constants,utils}` 已落地并被页面真实引用。
