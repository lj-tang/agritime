## 三、华为 ICT 大赛创新赛·赛题一 评估

### 赛题是什么（第十一届，2026-2027，当前进行中）

**赛题一：基于华为云产品打造 AI 创新应用**（开放型赛题，三题独立评审）

- 报名截止：**2026-11-30（还剩 16 天）**；初赛 2026-12（线上提交材料）→ 中国总决赛 2027-03 → 全球总决赛 2027-05（深圳）
- 场景不限（生活应用/行业应用等），评分侧重创新性（初赛占 60%），另看系统复杂度/技术复合性、商业价值/社会效益、功能完备性、答辩
- **硬性技术要求**：① 用华为云码道 CodeArts 代码智能体开发；② 基于已有智能体和 Skills 关联 RDS、Redis 等华为云服务快速开通创建；③ 作品部署在华为云上
- 入围后需开源至 Gitee/GitHub；演示真系统（代码与 PPT 对不上取消资格）
- 组队：同校 3 名学生 + 1 名指导老师；编程语言不限；**官方 Q&A 明确：团队自主开发的原创项目，结合华为云技术及码道优化后参赛是允许的**（不允许的是纯包装或第三方开源二次开发）

### 逐条对照：知农时能不能上

| 赛题要求 | 知农时现状 | 判定 |
|---|---|---|
| 应用场景不限、解决真实问题 | 农户「今天这活该不该干」，小切口真痛点，有演示文稿完整叙事 | ✅ 强契合 |
| AI（必选） | 大模型品种识别 / 播期推算 / 病害诊断，缺模型自动回落本地规程 | ✅ |
| 作品形态（Web/智能体均可） | Web 应用 + 微信小程序骨架 | ✅ |
| 功能完备性 | 8 大板块、25 接口、400 作物库、217 项测试全绿 | ✅ 突出 |
| 部署在华为云 | 115.175.44.27 就是华为云 ECS，服务在跑 | ✅ 基本满足 |
| 开源 | 已在 GitHub（lj-tang/agritime） | ✅ |
| 原创性 | 完全自主开发 | ✅ |
| **用码道 CodeArts 智能体开发** | 项目在本机 CodeArts IDE 下开发，但赛题指定的「码道代码智能体」（AI 智能体 + Skills）是否已在开发链路中使用需要落实 | ⚠️ 需补 |
| **关联 RDS、Redis 等华为云服务** | MySQL 是 ECS 上自建的手工安装，不是云托管 RDS；无 Redis | ⚠️ 需改造 |
| 组队报名 | — | ⚠️ 需在 11-30 前完成 |

### 结论与建议

**可以参赛，而且契合度相当高**——开放型赛题 + 农业真实痛点 + 功能完备 + 已上华为云 + 已开源，五项占先。要补的是三件事，都不难：

1. **数据库换 RDS（收益最大）**：把 ECS 自建 MySQL 迁到华为云 RDS for MySQL——代码零改动（连接串走环境变量 `STORE_MYSQL_URL`，本来就支持），正好满足「关联 RDS 快速开通」的赛题要求。
2. **加 Redis（顺手治病）**：目前大模型播期缓存是进程内 + 文件，重启即清（这是现状报告里的 P1 痛点）。引入华为云 Redis 做播期/天气缓存，既满足赛题「关联 Redis」，又直接消掉一个已知短板——评委问起来还是加分项。
3. **落实码道开发链路**：下载华为云码道 CodeArts 代码智能体，用它的智能生成/单元测试/Skills 做后续迭代，保留开发记录作为答辩证据。注意官方允许在码道里用第三方模型和插件。
4. **组织事项**：11-30 前官网组队（3 学生 + 1 指导老师，同校）；12 月初赛前要交技术文档、代码、演示视频——演示视频脚本今天已核对过与实现一致，可直接用。

**风险提示**：参赛资格要求在校学生（本科/硕士/博士）；每名选手只能报一个赛道；演示答辩以真系统为准——目前的线上环境和功能链路已能支撑。
